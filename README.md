### 🌟 Projetos em Destaque & Soluções de Engenharia

> 🔒 **Nota sobre Privacidade & Propriedade Intelectual:**  
> A maior parte do meu trabalho em produção e ferramentas de alta complexidade reside em repositórios privados e ambientes corporativos protegidos por **acordos de confidencialidade (NDA)**. Por envolverem dados fiscais e propriedade intelectual restrita, o código-fonte permanece privado. Abaixo estão os cases arquitetados e entregues sob essas diretrizes:

#### 1. 🖨️ BGR Editor — Web Studio (Domínio Sistemas)
> *Estúdio Web WYSIWYG completo construído via orquestração de IA para edição, conversão e compilação do formato binário proprietário `.bgr`.*
* **Engenharia Reversa de Binários:** Decodificação e compilação nativa de arquivos binários criptografados (XOR + zlib + sintaxe PowerBuilder DataWindow release 11.5).
* **Motor Inteligente PDF → BGR:** Pipeline que mapeia PDFs corporativos diretamente para elementos de relatório com calibração geométrica milimétrica A4 (escala 1:1).
* **Confiabilidade:** Suíte com mais de 85 testes automatizados cobrindo 15 setores do sistema para garantir zero falhas e zero regressões em produção.
* **Stack:** Python, Turso Cloud (libSQL), SQLite, Vanilla JS/CSS moderno, ODBC Sybase ASA e integração web.

#### 2. 🔄 Multi-ERP ETL & Migration Engine
> *Motor de extração, unificação e sanitização de dados conectando mais de 30 ERPs contábeis e de folha do mercado brasileiro.*
* **Engenharia de Dados em Escala:** Dicionário e catálogo de dados com mais de **5.100 tabelas mapeadas** e documentadas.
* **Interoperabilidade:** Pipelines de migração entre bancos legados heterogêneos (TOTVS Protheus, RM, Questor, Contmatic, Fortes, Senior Rubi, Domínio, Nasajon, WK Radar, etc.).
* **Integridade:** Tratamento de inconsistências relacionais e normalização de esquemas complexos.

#### 3. 🤖 DominioExplorer (RPA & Automação Windows Win32)
> *Framework de automação profunda para ERPs legados sem APIs públicas.*
* Controle de janelas MDI e monitoramento de fluxos contábeis e de folha via chamadas nativas da Windows API.
* Execução autônoma de rotinas críticas, extrações de relatórios e navegação de menus sem intervenção manual.
